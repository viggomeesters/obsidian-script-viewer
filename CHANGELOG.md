# Changelog

All notable changes to Script Viewer are documented here.

## 0.1.0 - 2026-06-08

- Initial local release.
- Add read-only source view for `.sh`, `.bash`, `.zsh`, `.bat`, `.cmd`, `.ps1`, `.ahk`, `.command`, and `.bats`.
- Add line numbers, soft wrap, search, source filtering, outline filtering, refresh, interpreter summary, risk hints, and render caps.
- Add parser fixtures and smoke checks for read-only and never-execute constraints.
